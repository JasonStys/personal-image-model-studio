## Browser dependency setup failure and correction

The original [browser job](https://github.com/JasonStys/personal-image-model-studio/actions/runs/42765057347/job/129659558135)
on `ubuntu-latest` resolved to Ubuntu 26.04 and spent its 20-minute budget in OS
dependency installation. Repeated HTTP Azure mirror package requests stalled for
roughly 30 seconds; official HTTPS archive fallbacks slowly succeeded. The run
ended canceled before browser, private-account or dependency-audit commands ran.
Those skipped commands are not represented as passing tests. Other model/native
gates were separate observations.

Only this browser job is pinned to supported Ubuntu 24.04. It reuses the reviewed
runner-only official HTTPS mirror setup: exact GitHub/Linux/x64/Ubuntu guards,
active mirror-file URI and archive keyring checks, preserved suites/components
and Signed-By verification, TAB-prioritized official archive/security mirrors,
and effective APT Acquire retry/15-second timeout assertions. It does not disable
TLS or package signatures, change a user's machine, or widen a test deadline.
The OS-dependency step has a 10-minute bound and locked browser download has a
5-minute bound inside the unchanged 20-minute job. All three browser engines,
private-account assertions and audit commands remain mandatory. Other platform
and native matrix jobs retain their original scope. Hosted acceptance of this
changed setup remains required; Windows local tests cannot prove the Linux fix.

Official runner setup reference: [configure-apt.sh](https://github.com/actions/runner-images/blob/main/images/ubuntu/scripts/build/configure-apt.sh).
