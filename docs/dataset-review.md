# Dataset review before training

This is a local evidence workflow for artists/model trainers, not an automatic dataset approval or rights-verification service.

1. Import images you own or may train on, or create the built-in owned procedural data. Ordinary training continues to exclude explicit AI-origin images and records with empty captions.
2. In **Datasets & glossary**, choose **Dataset to review**, then **Review dataset quality**. The full metadata summary covers at most 10,000 normalized imported records in an 8 MiB manifest. Malformed data or changed dataset identity fails explicitly.
3. Review caption gaps, declared origin/license notes, eligible split sizes and whether the existing 8-training/2-validation minimum is met. These counts are prerequisites, not quality scores or inferred authorization.
4. Inspect sample scope and file-integrity errors. The sample is deterministic by record hash and interleaves train/validation when both exist. At most 64 eligible images, 32 MiB of encoded bytes and 16,777,216 decoded pixels are inspected. AI-origin and uncaptioned records do not enter similarity comparisons. Missing/changed/unsafe sampled images are errors, not accepted evidence; unchecked eligible counts stay visible.
5. Inspect near-duplicate candidates. A 64-bit horizontal grayscale difference hash compares 9×8 thumbnails; Hamming distance ≤4 flags cross-split pairs for human review. At most 1,024 cross-split comparisons are possible with a balanced 64-image sample. Total candidate count and omitted count accompany at most 32 shown pairs. Flat fields, colors, crops and semantic changes can cause collisions or misses. Zero candidates does not prove a leak-free corpus.
6. **Preview candidate pair** fetches metadata-free PNG thumbnails (at most 192px) after validating the known imported file and pixel hashes. Preview errors remain explicit. Original files are not edited or served as arbitrary machine paths. Reports/previews require the same login, vault and account scope as other private data.
7. **Download reviewed dataset report** exports the exact displayed JSON, bound to dataset/report SHA-256. It includes metadata and candidate references, not source artwork or credentials. Exported files are plaintext under your control. Changing selection clears the export and revokes preview URLs; stale responses cannot populate a different selection.
8. Reconcile source issues yourself and import a new dataset. Review never changes pixels, captions, split assignments, quarantine, training selection or weights. Navigate to **Train & models** and explicitly choose approved datasets. No training or outside request starts from review.

The dataset fingerprint is the existing import identity over hashes/captions/origins/splits. The report hash binds the generated dossier. Neither is a digital signature or legal assurance. The API accepts registered dataset IDs only; all displayed strings use text nodes. The legacy token mode is still single-user developer mode; default account mode preserves private encrypted archives and token-free browser URLs.

Code: `studio/dataset_review.py`, `studio/api.py`, `web/workspace.ts`, `web/api.ts`. Verification: `tests/test_dataset_review.py`, the real private browser trainer journey, `tests/test_private_ml.py`, real browser-to-ML workflow and `scripts/smoke_native.py`. The latter gates verify review followed by actual optimizer/sampler/account/encrypted-reopen behavior in the configured ML/native environment.
