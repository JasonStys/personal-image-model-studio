# Optional licensed hand-drawing sample

This example uses a small public [Quick, Draw! dataset](https://github.com/googlecreativelab/quickdraw-dataset) subset made available by Google, Inc. under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). `scripts/prepare_quickdraw.py` selects up to 128 unique recognized drawings each of sun, flower and fish. It streams bounded category prefixes, never the full corpus. Simplified vectors become centered antialiased 32×32 raster images with category captions. Participant location/time metadata is discarded. This prefix sample is not representative; provenance labels are not an AI-origin or visual-safety detector. Inspect the sample before reuse.

```bash
python -m scripts.prepare_quickdraw --download --output artifacts/quickdraw-sample --per-category 128
```

In Datasets & glossary, import that directory after reviewing the license. In Train & models, select the imported dataset, native/from-scratch mode, CPU, resolution 32, batch 16, learning rate 0.001 and a bounded step/time budget. This trains fresh weights, not an adapter on a downloaded base. Use prompts such as `black line drawing of flower on white background`; generation is learned inference, not replay of source strokes. The model is only a small functional example, not a polished illustrator or general-purpose artwork model.

Test plan: offline fixtures exercise coordinate validation, finite values, line/byte limits, fixed-host/range downloads, duplicate removal, attribution, overwrite protection and failure cleanup. Real validation separately checks import counts, disjoint normalized-pixel splits, completed optimization, finite checkpoint tensors, held-out denoising measurements, repeatable seeds and actual browser generation. No network download or account access is used by CI's parser tests. Noise loss alone does not measure visual quality or semantic correctness.

To evaluate a completed model against its imported dataset and create nine actual learned samples plus a sanitized report:

```bash
python -m scripts.evaluate_quickdraw --model PATH_TO_CHECKPOINT --dataset PATH_TO_IMPORTED_DATASET --output artifacts/new-sketch-evaluation
```

The evaluator verifies attribution, model/data fingerprints, finite tensors, improved held-out denoising and same-stack seed replay. It writes only generated samples and measurements; no source drawings, participant metadata, account IDs or weights are copied to the public report. Keep input files/weights under ignored runtime or artifact folders. Public evidence must retain this source/license notice.

Debugging note: the first offline test run exposed Windows temporary-path failures from autogenerated byte-payload test names and accidental duplicate raster fixtures. Short explicit test IDs and distinct coordinate fixtures resolved those issues; all 16 importer cases then passed. Initial source-sheet inspection from the restricted execution identity could not read the privately created sample; it was repeated with scoped read permission and an asserted 384-file count, without changing dataset ACLs. These initial failures are not successful tests or artwork-learning claims.

Rollback: this optional recipe changes no existing models, accounts or system settings. Keep each sample/model in a new local ignored directory and simply select a previous model to return to it. No automatic download/training occurs on app launch or in CI.
