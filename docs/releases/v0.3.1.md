# Personal Image Model Studio 0.3.1

By Jason Stys. The CPU application gains a native owner window with Open, Help,
actual runtime notices and completion-aware Quit. Account paths, encrypted vault
format and original native-model training/generation workflows are retained.

Packages use final CPython3.14.10, actual Tcl/Tk identity, complete dependency terms,
pre-initialization profile guards and process-local vendor telemetry opt-out. No
pretrained weights, artwork or provider credentials are distributed.

Release assembly requires original source/ML checks, actual extracted CPU/browser
workflows on all three supported platforms and processed exact-main CodeQL. The
draft stays unpublished until independently downloaded/installed validation is
reviewed. No automatic publication or asset replacement is supported. See the
[native delivery guide](https://github.com/JasonStys/personal-image-model-studio/blob/main/docs/native-application.md).

These unsigned portable CPU apps are not signed installers, notarized apps, public
hosting or native mobile packages. Small model tests prove execution, not visual
quality. Retain stopped-profile backups and the previous app. Optional classic
SD/LoRA requires the full source environment and explicitly trusted runtime.

successful creation. Existing drafts are never retargeted or overwritten.
