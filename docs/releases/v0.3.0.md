# Personal Image Model Studio 0.3.0 — Jason Stys

A private local CPU application with a practical dataset review before real custom-model training. Existing native training, generation, resumable weights, image edits, account encryption and authorized connector features remain available.

- Review caption completeness, declared origins/license notes, eligible split sizes and training-count prerequisites. The report has dataset/report SHA-256 identities.
- Check file/pixel integrity on an explicit bounded sample and flag grayscale difference-hash near-duplicate candidates across training/validation. Preview actual private candidate thumbnails and download the exact reviewed JSON.
- A changed selection drops the prior report/export and ignores stale responses. Review never changes captions, splits, quarantine, training selection or model weights.
- Existing account/CSRF/loopback/vault boundaries apply to reports and thumbnails. All source images stay local; no new telemetry, remote API call, model download or artwork download occurs.
- Patched stable Vite tooling; descriptor-bounded JSON reads. Coherent new 0.3.0 build, health, release and packaged smoke checks.

No account/data schema migration is needed. Version 0.2.0 published assets and notes remain untouched for rollback. The new draft may publish only after exact-source validation and actual three-platform packaged account/training/generation/encrypted-reopen checks, including dataset review.

**Limits:** unsigned portable executable, not a signed/notarized installer; one unlocked local engine. Integrity/similarity sampling is capped at 64 images, 32 MiB encoded bytes and 16,777,216 decoded pixels; at most 32 candidate pairs are shown, with total/truncation counts. Grayscale hash similarity is not proof of duplication/leakage, an AI-origin detector or a semantic quality score. Rights labels are operator declarations, not legal verification. No candidates does not prove an entire dataset leak-free. The compact native model remains a small learned generator, not a photorealistic general model.
